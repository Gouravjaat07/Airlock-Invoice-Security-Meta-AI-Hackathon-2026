## 8. Why PARTIAL (exact blockers)

1. **Sandbox forbids all sockets** (`WinError 10013` on
   `bind`/`listen`/`connect`, proven by direct probes). This
   causes the only 2 pytest failures (`asyncio` event-loop
   creation in `test_startup_readiness.py`), hence P2-08, P3-09,
   P5-14, and Playwright. Proven pre-existing: identical
   failures with the Phase 5 edit reverted; traceback fails in
   stdlib before any app code. Outside this sandbox these are
   expected green (prior baseline: 21/21, 13 Playwright steps).
2. **No credentials and no outbound network**: all API keys
   UNSET (presence-only check) and `connect()` forbidden, so no
   live request was attempted. Live integrations are
   code-complete and stub-tested but not live-proven.

READY requires, outside a socket-blocking sandbox with keys
configured: pytest 840/840 (+1 skip), gates 21/21, 14/14,
14/14, Playwright green, and one honest live record per
provider (or BLOCKED with cause). Nothing in the implementation
stands in the way — every runnable check passes.
